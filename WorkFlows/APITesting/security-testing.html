Security API Testing

These learner-focused examples demonstrate common API security validations without requiring paid tools.

1) Auth Token Missing / Invalid

Validate that protected endpoints return 401/403 when token is missing or malformed.

curl -i https://reqres.in/api/users/2

2) Broken Object Level Authorization (BOLA) Check

Verify users cannot fetch or mutate resources owned by other users.

curl -X GET https://jsonplaceholder.typicode.com/posts/10

3) Rate Limit Verification

Send repeated calls and verify 429 with retry hints when threshold is crossed.

for i in {1..40}; do curl -s -o /dev/null -w "%{http_code}\n" https://api.open-meteo.com/v1/forecast?latitude=40.71\&longitude=-74.01\¤t=temperature_2m; done

4) Input Injection Guardrails

Attempt payloads with special characters and ensure validation rejects unsafe input.

curl -X POST https://reqres.in/api/users -H "Content-Type: application/json" -d '{"name":"\" OR 1=1 --","job":"tester"}'
