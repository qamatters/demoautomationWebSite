# QA Automation Academy Product Plan

## Product positioning
A practical learning platform for QA engineers to learn automation from beginner to job-ready, based on realistic end-to-end business scenarios.

## Why static architecture is sufficient now
- Current labs are simulation-first and don't require persistent user accounts.
- Static hosting keeps costs low and global performance high.
- Most automation scenarios (UI/API/security/performance basics) can be taught through deterministic client-side simulations.

## Phase 2 (when to introduce backend)
Introduce a Spring Boot backend + React frontend when these become priorities:
- Learner login, progress tracking, and certification.
- Team dashboards and assignment management.
- Multi-tenant enterprise/white-label offerings.
- Paid subscriptions and secure content delivery.

## Monetization model
1. **Freemium**: free core labs + paid advanced challenge packs.
2. **Team Plan**: instructor analytics and cohort management.
3. **Certification**: paid practical assessments with badges.
4. **Enterprise**: on-prem/deployment package for internal L&D teams.

## Feature backlog
- API contract-testing module (OpenAPI diff drills).
- Security module with guided OWASP checkpoints.
- Performance module with downloadable JMeter/k6 scripts.
- Interview preparation mode with timed tasks.
